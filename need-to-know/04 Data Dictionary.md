# 04 · Data Dictionary

**Project:** PiQuaChu 🛡️
**Purpose:** Canonical definitions of every data structure, field, enum and value the
system produces or persists.

---

## 1. Finding (scan result unit)

Produced by the scanner engines; persisted per scan; rendered in the findings table.

| Field | Type | Description / Values |
|---|---|---|
| `file` | string | Repo-relative path (temp prefix stripped) |
| `line` | int | 1-based line number of the match |
| `vulnerability` | string | Rule id, e.g. `deprecated-rsa-java`, `pqc-fndsa-java`, `key-file-rsa`, `dependency-vulnerable-version` |
| `severity` | enum | `ERROR` (Shor-broken/defunct → shown as CRITICAL/FAIL) · `WARNING` (weakened → WARN) · `INFO` (positive PQC evidence → PASS) |
| `recommendation` | string | Human-readable remediation incl. the FIPS migration target |
| `nist_standard` | string | `FIPS 203` / `FIPS 204` / `FIPS 205` / `FIPS 206` / `FIPS 202` / `Advisory` |
| `category` | enum | `key-encapsulation` · `signatures` · `hashing` · `symmetric` · `tls` · `secrets` · `kdf` · `randomness` · `dependencies` · `hybrid` · `unknown` |
| `pqc_compliant` | bool | `true` = NIST-approved PQC usage (positive evidence) |
| `target_algorithm` | string | Migration target, e.g. `ML-KEM (hybrid X25519MLKEM768)`, `ML-DSA / SLH-DSA` |
| `verdict` | enum | `PASS` · `WARN` · `FAIL` (derived from severity/pqc flag) |
| `algorithm` | string | Concrete algorithm name when known (deps/keyfiles findings) |
| `key_size` | string | When known (e.g. RSA-2048) |
| `snippet` | string | ±N context lines around the match |

## 2. Compliance matrix (per scan)

Built by `compliance.py::build_matrix`.

| Field | Type | Description |
|---|---|---|
| `pqc_score` | int 0–100 | **Readiness** score: starts 100; ERROR legacy −20; WARNING legacy −10; each compliant usage +5; clamped |
| `risk_score` | int 0–100 | **Weighted danger**: Σ(category_weight × severity_factor) × 100 / 5, saturating. Weights: key-encapsulation 1.0, signatures 1.0, symmetric 0.8, secrets 0.7, randomness 0.7, hashing 0.6, kdf 0.5, tls 0.5, dependencies 0.4, hybrid 0.1, unknown 0.3. Severity factors: ERROR 1.0, WARNING 0.5, INFO 0.0 |
| `risk_level` | enum | `critical` ≥80 · `high` ≥50 · `medium` ≥20 · `low` <20 |
| `verdict` | enum | `non_compliant` (worst) · `at_risk` · `transitional` · `compliant` · `not_detected` |
| `summary` | string | Human-readable audit summary |
| `findings_count` | int | Total findings in scan |
| `standards` | map (below) | One entry per FIPS standard |
| `advisory` | map | Counts per advisory bucket: `hashing`, `symmetric`, `tls`, `secrets`, `dependencies`, `kdf`, `randomness`, `total` |

### 2.1 Per-standard entry (`standards["FIPS 20x"]`)

| Field | Type | Values |
|---|---|---|
| `algorithm` | string | `ML-KEM` / `ML-DSA` / `SLH-DSA` / `FN-DSA` |
| `former` | string | `CRYSTALS-Kyber` / `CRYSTALS-Dilithium` / `SPHINCS+` / `FALCON` |
| `role` | string | e.g. `Key Encapsulation — general encryption` |
| `status` | enum | `compliant` (only PQC of that category) · `partial` (PQC + legacy coexist) · `non_compliant` (only legacy) · `not_detected` (no crypto of that category) · `transitional` (hybrid evidence) |
| `compliant_count` | int | Positive PQC findings for that standard |
| `legacy_count` | int | Legacy findings mapping to that standard |
| `severity` | enum | `ok` · `warning` · `critical` (UI color key) |

## 3. Remediation plan (per legacy finding)

Generated by `remediation.py`; persisted in `remediation_plans`.

| Field | Type | Description |
|---|---|---|
| `file` / `line` | string/int | Finding location |
| `rule` | string | Source rule id |
| `standard` | string | FIPS standard the plan targets |
| `plan.replacement_code` | string | Complete copy-pasteable drop-in snippet (imports included) for the target language |
| `plan.dependencies` | string | Package/library change, e.g. `pip install liboqs-python` |
| `plan.justification` | string | Quantum threat-model rationale |
| `plan.risk` | enum | `low` / `medium` / `high` if migration is skipped |
| `plan.source` | enum | `local-rule-engine` (deterministic default) · `groq` (LLM enrichment; metadata only) |

## 4. Job (async scan pipeline record)

Persisted in `jobs` table; polled by the frontend.

| Field | Type | Values / Notes |
|---|---|---|
| `id` | uuid string | Task id returned by `POST /api/v1/sast-scan` |
| `status` | enum | `PENDING` → `ANALYSING` → `SUCCESS` \| `FAILED` |
| `scan_id` | int/null | Set once findings are persisted |
| `payload` | JSON | `{type: "sast"|"telemetry-audit", zip_path, temp_dir, filename, …}` |
| `result` | JSON | On success: `{scan_id, engine, findings, compliance, remediation_plans, count}` |
| `logs` | JSON array | Append-only terminal stream, capped 500 entries: `{t, level, message}` |
| `created_at` / `updated_at` | ISO string | Timestamps |

## 6. CBOM (CycloneDX 1.7 JSON)

Generated by `cbom.py`.

| Section | Contents |
|---|---|
| `bomFormat` / `specVersion` | `CycloneDX` / `1.7` |
| `metadata.tools` | `PiQuaChu 2.2.0` (CycloneDX 1.6+ tools object) |
| `metadata.properties` | `piquachu:pqc_score`, `risk_score`, `verdict`, assessment status, registry review date, policy-finding count |
| `components[]` | `type: "cryptographic-asset"`, `cryptoProperties` (`algorithm`, `related-crypto-material`, `protocol`), evidence occurrences with relative paths, namespaced `piquachu:*` properties |
| `vulnerabilities[]` | Genuine CVE advisories only (e.g. dependency matches); policy findings are not serialized here |
| `vulnerabilities[]` | `id` (`CS-<scan>-NNN`), `ratings[]` (severity mapped high/medium/info), `affects[].ref`, properties: `evidence_file`, `evidence_line`, `rule`, `recommendation`, `nist_standard` |

## 7. Anonymized telemetry (zero-trust payload)

The *only* structure permitted to leave the machine via `cipher_cli.py telemetry` →
`POST /api/v1/compliance/check`.

```json
{
  "telemetry": {
    "algorithm_telemetry": [
      {"algorithm": "RSA", "standard": "FIPS 203", "severity": "ERROR",
       "verdict": "FAIL", "count": 3}
    ]
  },
  "summary": {"pqc_score": 42, "verdict": "non_compliant"}
}
```

Guarantee: **no file paths, no variable names, no source snippets.**

| `severity` | ERROR / WARNING / INFO |

| `metadata.pqc_compliant` | true/false |
| `metadata.target_algorithm` | migration target string |
